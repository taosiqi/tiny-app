# TinyPress

一款基于 Tauri + React 的本地文件优化工作台，支持：

- 统一任务中心（文件自动识别、统一队列、历史记录）
- TinyPNG 图片压缩（PNG / JPG / JPEG）
- 音频压缩（MP3 / OGG / WAV，基于 ffmpeg）
- 压缩结果对比、独立文件对比、备份还原、目录递归处理

---

## 功能特性

### 任务中心（2.0）

- 支持统一添加文件或目录，并自动识别图片、音频和目录 / 未知输入
- 支持“平衡 / 最小体积 / 验证优先”三种批处理预设
- 图片与音频任务共用一个处理日志，方便查看成功、跳过和失败结果
- 成功压缩后可直接在任务中心查看压缩前后对比
- 自动保存最近 30 次任务历史，可筛选、搜索、回看结果、删除单条记录或清空历史
- 支持失败项重试、成功项批量还原，以及 JSON / CSV 报告导出
- 内置健康面板，集中查看 TinyPNG Key、音频引擎、队列和最近结果状态

### 图片压缩（TinyPNG）

- 支持多 API Key 管理（本地持久化）
- 支持 API Key 有效性检查与当月已用次数展示
- 单 Key 达到上限（429）后自动切换其他 Key
- 全部 Key 用尽时自动暂停，可补充 Key 后继续
- 支持一键校验全部 Key，并优先使用剩余额度更多的 Key
- 保留压缩日志与统计（成功 / 跳过 / 失败 / 节省体积）
- 支持日志筛选、清空日志、失败项重试

### 音频压缩（ffmpeg）

- 一个音频压缩入口内支持“混合 / MP3 / OGG / WAV”模式
- 混合模式可一次添加 MP3、OGG、WAV 文件或目录，并按原扩展名自动选择压缩策略
- MP3：`64kbps`、单声道、`44.1kHz`
- OGG：`libvorbis`、`96kbps`、`44.1kHz`
- WAV：`pcm_s16le`、单声道、`22.05kHz`
- 若压缩后体积未减小，会自动跳过，不覆盖原文件
- 支持任务暂停、失败项重试、压缩前后试听对比

### 对比与还原

- 压缩前自动备份原文件到同目录 `_tiny_backup/`
- 备份采用“首次原始备份”策略，重复压缩不会覆盖最初备份
- 对比面板支持查看压缩前后体积、图片滑块对比、音频试听与媒体元信息
- 支持一键还原（将备份覆盖回原文件），还原前会确认并检查备份状态

### 文件对比

- 支持从“文件对比”页面选择任意两个文件
- 图片：滑块预览、尺寸、大小、修改时间
- 音频：双播放器、时长、编码、采样率、声道、码率
- 文本：`.txt`、`.json`、`.md`、`.css`、`.js` 等行级差异
- 其他二进制文件：大小、扩展名、修改时间、SHA-256 与一致性判断

### 路径处理

- 支持“添加文件”与“添加目录”
- 支持“递归子目录”开关
- 自动跳过 `_tiny_backup` 目录，避免重复处理备份文件

## 使用说明

### 任务中心

1. 打开“任务中心”
2. 添加文件或目录
3. 选择批处理预设，按需开启“递归子目录”
4. 点击“开始统一处理”
5. 在“处理日志 / 结果对比 / 历史记录 / 健康面板”查看本次任务
6. 必要时可重试失败项、批量还原成功项，或导出 JSON / CSV 报告

> 图片任务仍需要先在“图片压缩”页配置 TinyPNG API Key。

### 图片压缩

1. 打开“图片压缩”页签
2. 添加并校验 TinyPNG API Key
3. 添加图片文件或目录
4. 按需开启“递归子目录”
5. 点击“开始压缩”
6. 在“处理日志 / 压缩对比”查看结果，必要时可“还原”

### 音频压缩

1. 打开“音频压缩”页签
2. 选择“混合”或指定 MP3 / OGG / WAV 单格式模式
3. 添加音频文件或目录
4. 点击“开始压缩”
5. 可在处理中暂停任务，失败项可单独重试
6. 在“处理日志 / 压缩对比”查看结果，必要时可“还原”

### 文件对比

1. 打开“文件对比”页签
2. 分别选择文件 A 和文件 B
3. 查看图片、音频、文本或二进制文件的差异结果
4. 必要时可交换左右文件、打开文件位置或复制差异内容

## 常见问题

### 1) TinyPNG Key 显示无效或超时

- 检查网络是否可访问 `api.tinify.com`
- 确认 Key 是否填写正确
- 若提示当月上限，可新增其他 Key 继续

### 2) 为什么有些文件被“跳过”

- 当压缩后体积不小于原文件时，程序会跳过并保留原文件

### 3) 备份文件在哪里

- 位于原文件同目录下的 `_tiny_backup/`
- TinyPress 默认保留首次原始备份，后续重复压缩不会覆盖这个备份

### 4) ffmpeg 找不到怎么办

- 开发环境默认使用 `node_modules/ffmpeg-static/ffmpeg`
- 打包环境会随 Tauri bundle 带入 ffmpeg
- 也可以通过 `FFMPEG_PATH=/path/to/ffmpeg pnpm dev` 指定自定义 ffmpeg
